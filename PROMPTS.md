**Topic: Authentication and Password Security**

**Prompt:** Help implement secure user login and registration in Flask, including password hashing and session management.

**AI Assistance:** Provided guidance on password hashing, login validation, and secure session handling.

**Prompt:** Help implement admin, owner, and viewer roles with server-side authorization checks to prevent unauthorized users from accessing documents.

**Prompt:** Help implement document-level read and edit permissions so owners can share documents with specific users and revoke access.

**AI Assistance:** Provided guidance on permission validation and access revocation.

**Prompt:** Help test authentication, role-based permissions, document access restrictions, and audit integrity. Also help prepare the Flask application for deployment.
